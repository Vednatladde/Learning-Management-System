Lesson 1.2: Core Design Concepts

schedule 15 min read
visibility 1.2k students viewed

This lesson covers the fundamental principles of UI design, including alignment, proximity, and contrast. Understanding these concepts is crucial for creating intuitive user interfaces. We will explore how these elements work together to guide the user's eye and improve usability across different platforms.

Watch: Visual Hierarchy Masterclass

1. Alignment

Alignment creates a sharp, ordered appearance. Nothing should be placed on a page arbitrarily. Every element should have some visual connection with another element on the page. This creates a clean, sophisticated look.

  • Horizontal Alignment: Keeping elements in a row balanced.
  • Vertical Alignment: Ensuring text and icons share a common baseline.
  • Edge Alignment: Using grids to define the boundaries of your layout.

2. Proximity

Proximity is about grouping related items together. When several items are in close proximity to each other, they become one visual unit rather than several separate units. This helps organize information, reduces clutter, and gives the reader a clear structure.

lightbulb Pro Tip

Whitespace is not "empty space." It is a powerful tool for defining proximity. Use it to separate distinct modules of content.
